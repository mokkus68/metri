# Metri Percorsi Precisione (PWA)

Un'applicazione web leggera per Android progettata per misurare con precisione la distanza percorsa a piedi, unendo la sensibilità del **contapassi calibrato** tramite accelerometro al tracciamento **GPS**.

## Caratteristiche
- **Doppio sistema di misurazione:** Sfrutta sia i passi (per i brevi tratti e la massima precisione metrica) sia il GPS (per gli spostamenti all'aperto).
- **Calibrazione personalizzata:** Possibilità di impostare la lunghezza esatta del proprio passo.
- **Installabile (PWA):** Può essere aggiunta direttamente alla schermata Home di Android come un'app nativa.

## Come usarla
1. Apri la pagina dal browser Chrome su Android.
2. Consenti l'accesso alla **posizione** e ai **sensori di movimento**.
3. Inserisci la lunghezza media del tuo passo nella sezione di calibrazione.
4. Tocca **AVVIA** per iniziare a camminare.
